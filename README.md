# STORAGE&MESS

Мессенджер с хранилищем файлов: личные и групповые чаты, файлы любого размера
с докачкой, голосовые и видеокружки, звонки (WebRTC + свой STUN/TURN), офлайн-
кэш и очередь отправки, PWA. Сервер — Node.js/TypeScript + SQLite, клиент —
React + Vite (тот же интерфейс работает в браузере, в APK и на десктопе).

Клиент для LoRa-сетей Meshtastic (STM32 и Linux) — отдельный репозиторий
`smess-lora`.

## Что не входит в открытый код

Закрытая часть STORAGE&MESS заменена заглушками с тем же интерфейсом —
открытая сборка компилируется и работает, просто без этих механизмов:

| Механизм | Файл-заглушка |
|---|---|
| Сквозное шифрование сообщений | `web-client/src/lib/e2ee.ts`, `server/src/routes/e2ee.routes.ts` |
| Шифрование звонков, маскировка SDP | `web-client/src/lib/call-crypto.ts` |
| Шифрование файлов на диске | `server/src/services/file-encryption.service.ts` |
| Защита от DPI | `server/src/services/dpi-protection.service.ts`, `dpi-analyzer.service.ts` |

Набор эмодзи (картинки Apple) в репозиторий не входит — у него своя лицензия.

## Свой сервер (самохост) — одной командой

```bash
tools/selfhost.sh
```

Скрипт ставит зависимости, собирает веб и сервер, создаёт `server/.env` со
случайными секретами и самоподписанный сертификат на адреса машины, и
запускает сервер на `https://<адрес>:8443` (порт — `SMESS_PORT`).

Сервер работает и **без интернета**: телефоны и десктопы в той же сети
находят его сами — Настройки → «Свой сервер» → «Найти сервер рядом»
(широковещательный UDP 47620, отключить — `LAN_DISCOVERY=0` в `.env`).

## Аварийная связь

- **Без сервера:** приложение открывается из локальной базы, написанное уходит
  само, когда связь вернётся.
- **Bluetooth-mesh:** телефоны рядом передают сообщения друг другу.
- **LoRa (Meshtastic):** свой узел по Bluetooth (телефон) или USB (браузер,
  десктоп) — сообщения чатов идут в эфир на километры. Протокол —
  `web-client/src/lib/lora`, совместим с клиентом для STM32 (`smess-lora`).
- **Шлюз LoRa ↔ сервер:** `tools/lora-gateway` — узел по USB на машине
  сервера, эфир попадает в группу «📡 LoRa-эфир» и обратно.

У сообщения один сквозной номер (`client_id`) на всех путях — копии,
пришедшие по mesh, LoRa и с сервера, склеиваются без дублей.
